# 유튜브 라이브 ui

Chrome·Microsoft Edge용 YouTube 라이브 확장 프로그램입니다. **기본 모드**에서는 영상의 원래 위치를 유지하고 오른쪽 채팅이 페이지 스크롤을 따라오게 합니다. **가로 영화관 모드**에서는 원래 영상·채팅 배치를 유지하고 추천 영상을 채널·설명 아래에 모읍니다. **세로 영화관 모드**에서는 YouTube 상단바를 숨기고 영상 → 채널·제목·설명 → 채팅 순서로 배치합니다. 현재 파일 버전은 **1.0.12**입니다. 실제 사이트 검증은 아래 버전별 기록을 참고하세요.

## 1.0.12 변경 내용

- 확장 이름을 **유튜브 라이브 ui**로 변경했습니다.
- 아이콘을 빨간 YouTube 형태에 흰색 L이 들어간 디자인으로 변경했습니다.
- 이름과 아이콘만 변경했으며 배치·채팅·추천 영상 기능은 1.0.11과 같습니다. 아래 실제 Edge·YouTube 검증 기록은 1.0.11 및 해당 이전 버전에서 확인한 결과입니다.

## 1.0.11 변경 내용

- 일반 추천 영상의 열 수를 **가로 화면 최대 4개, 세로 기본 모드 최대 2개, 세로 영화관 모드 최대 3개**로 제한합니다. 기본 모드에서 최대 열 수가 빠져 7개씩 보이던 문제를 수정했습니다. 창이 좁으면 열 수는 더 줄어듭니다.
- 세로 화면의 Shorts 확대도 기본·영화관 모드 공통으로 적용합니다. 화면 비율은 1.0.9의 3% 허용 기준을 사용합니다.
- 기본 모드에서 기존 오른쪽 채팅의 감싸는 요소를 sticky로 처리해 페이지를 위아래로 스크롤해도 화면 안에 따라옵니다. 입력 영역을 위한 높이를 유지하며, 영상·채팅·iframe의 부모를 바꾸지 않습니다.
- 기본 모드의 채팅 하단에 12px 여백을 확보합니다. 페이지 맨 아래에서 원래 바깥 여백이 더 큰 경우에는 그 여백을 유지합니다. 세로 영화관 모드는 여백 없이 화면 맨 아래까지 채웁니다.
- 1.0.10의 영화관 → 기본 모드 복귀 시 재생 바 크기 복구를 유지합니다.

## 1.0.10 변경 내용

- 가로 영화관 모드의 일반 추천 영상은 **한 줄 최대 4개**입니다. 카드 최소 너비 300px를 기준으로 창이 좁아지면 3·2·1열로 줄어듭니다.
- 세로 영화관 모드의 일반 추천 영상은 **한 줄 최대 3개**입니다. 카드 최소 너비 220px를 기준으로 창이 좁아지면 2·1열로 줄어듭니다.
- 세로 영화관 모드의 Shorts는 목록 폭을 4등분한 폭을 기준으로 확대합니다. 최소 폭 220px를 사용하되 아주 좁은 화면에서는 목록 폭을 넘지 않으며, 썸네일의 원래 세로 비율과 기존 좌우 넘기기를 유지합니다. 가로 영화관 모드의 Shorts 크기는 유지합니다.
- 가로 영화관 → 기본 모드에서 재생 바와 영상 크기가 이전 폭에 남던 문제를 수정했습니다. 모드 변경 전에 확장 배치를 해제하고, YouTube의 전환 후 복구된 크기를 다시 계산하도록 알립니다. 버튼·키보드 전환과 속성 변경에 모두 대응합니다.
- 1.0.9의 정사각형 부근 3% 허용 범위는 유지합니다. 영상·채팅 노드는 옮기거나 교체하지 않습니다.

## 1.0.9 변경 내용

- 사용자의 요청에 따라 거의 정사각형인 창도 세로 영화관 배치를 사용합니다. 웹페이지 표시 영역의 **너비가 높이의 103% 이하**이면 적용합니다. 경계값도 포함합니다.
- 예를 들어 표시 영역이 **1255 × 1246px**인 떠 있는 창은 세로 배치가 됩니다. **1030 × 1000px**도 세로 배치이고, **1031 × 1000px**이면 가로 배치입니다.
- 창 고정 여부는 검사하지 않습니다. 표시 영역을 기준으로 하므로 탭·주소창·북마크바·디버깅 안내 바 등은 사용 가능한 높이에 영향을 줍니다.
- 영상의 재생·일시중지·음소거 및 브라우저 자동 재생 설정은 변경하지 않습니다.

## 1.0.8 변경 내용

가로 영화관 모드의 일반 추천 영상을 더 크게 표시하고, Shorts 줄 앞뒤에 생기는 큰 빈칸을 채우는 버전입니다. **1.0.8의 로컬 렌더링과 실제 Edge·YouTube에서의 추천 카드 확대 및 빈칸 채우기를 확인했습니다.**

- 가로 영화관 모드의 일반 추천 카드 최소 너비를 220px에서 300px로 늘렸습니다. Shorts 크기는 유지합니다.
- 추천 그리드가 앞줄의 빈자리에 뒤의 일반 영상 카드를 채우도록 변경했습니다.
- 1.0.7에서 추가한 빈 보조 열 접기와 영상·채팅 보존 동작은 유지합니다.

## 배치와 설정

### 기본 모드

- 영상은 YouTube의 원래 위치를 유지합니다. 오른쪽 채팅은 페이지를 위아래로 스크롤하면 YouTube 상단바 아래에 붙어 따라옵니다.
- 채팅은 화면 하단에서 12px 여백을 남기고 남은 높이를 채웁니다. 내부 메시지 스크롤과 채팅 입력은 기존 요소를 사용합니다.
- 추천 영상은 오른쪽 목록 대신 설명 아래에 모아 배치합니다. 가로 화면은 한 줄 최대 4개, 세로 화면은 최대 2개입니다. 아래로 스크롤하면 볼 수 있습니다.
- 기본 모드 개선은 가로·세로 화면 모두에 적용됩니다.

### 가로 영화관 모드

- 표시 영역의 너비가 높이의 103%를 초과할 때 적용합니다.
- 영상과 라이브 채팅, YouTube 로고·검색 상단바는 원래 영화관 모드 배치를 유지합니다.
- 추천 영상은 채널·설명 아래에 카탈로그로 모아 배치합니다. 페이지를 아래로 스크롤하면 볼 수 있습니다.
- 일반 추천 카드는 한 줄 최대 4개, 최소 300px를 기준으로 배치하며, 화면이 좁으면 사용 가능한 너비에 맞춥니다. Shorts 크기는 별도로 유지합니다.
- 기본 모드의 채팅 높이 확장은 적용하지 않습니다.

### 세로 영화관 모드

YouTube의 **영화관 모드**를 켜고 웹페이지 표시 영역의 **너비가 높이의 103% 이하일 때** 적용합니다. 세로로 긴 화면과 거의 정사각형인 화면이 대상입니다. 주소창·탭 표시줄을 포함한 창 외곽 크기로 판정하지 않습니다.

- YouTube 로고·검색창이 있는 상단바를 숨깁니다. 확보한 상단바 높이는 영상 크기를 늘리는 데 쓰지 않고 채팅에 더합니다.
- 맨 위: 영상. 영상 외곽의 흰 여백을 없애고 종횡비를 유지합니다. 비율을 보존하기 위한 검은 여백은 생길 수 있습니다.
- 영상 바로 아래: 채널·제목·버튼과 설명을 표시합니다. YouTube 원래 제목 요소를 채널 옆으로 옮기고, 기본 모드로 돌아가면 원래 자리로 복구합니다. 긴 제목은 한 줄로 줄여 표시합니다.
- 방송 정보 바로 아래: 라이브 채팅. 여백 없이 화면 맨 아래까지 채우고, 페이지를 스크롤하지 않아도 채팅 입력 영역을 볼 수 있도록 공간을 확보합니다. 채팅 하단 모서리는 12px로 둥글게 처리합니다.
- 채팅 아래: 일반 추천 영상은 한 줄 최대 3개입니다. Shorts도 목록 폭에 맞춰 확대합니다. 페이지를 아래로 스크롤하면 볼 수 있습니다.

별도의 오른쪽 정보 패널은 사용하지 않습니다. 설명을 펼쳐 내용이 길어지면 **방송 정보 영역 안에서 스크롤**합니다. 설명 때문에 페이지 전체가 길어져 채팅 입력 영역이 화면 밖으로 밀리지 않도록 정보 영역의 높이를 제한합니다.

영화관 모드에서 너비가 높이의 103%를 초과하면 위의 가로 영화관 모드로 전환합니다. 영상·채팅은 원래 배치로 돌아가고 추천 카탈로그는 채널·설명 아래에 유지됩니다. 세로 배치 대상이어도 표시 영역 높이가 **500 CSS 픽셀 미만**이면 공간이 부족하므로 YouTube 원래 배치를 사용합니다. 영화관 모드를 끄면 위의 기본 모드 개선을 적용합니다.

YouTube 상단바는 기본 모드, 가로 영화관 모드, 확장 기능 OFF, 플레이어 전체화면 등 세로 영화관 배치가 적용되지 않는 상태에서는 원래 동작으로 복구합니다.

### 공통 동작

- 일반 추천 영상은 가로 화면 최대 4열, 세로 기본 모드 최대 2열, 세로 영화관 모드 최대 3열입니다. Shorts 확대는 세로 화면에서 적용합니다.
- 채팅 필터는 YouTube 또는 사용자가 정한 상태를 유지합니다. 확장이 주요 채팅·실시간 채팅을 자동으로 선택하거나 변경하지 않습니다.
- 확장 아이콘의 스위치로 기능을 켜거나 끕니다. 설정은 브라우저에 저장되고 같은 브라우저의 YouTube 탭에 적용됩니다.
- 일반 영상, 종료된 방송의 채팅 다시보기, 채팅이 없는 영상, 플레이어 전체화면, 미니플레이어에서는 YouTube 기본 배치를 사용합니다.
- 숨긴 채팅을 강제로 다시 열지 않습니다.
- YouTube 내부 영상 이동에도 자동 대응합니다.

브라우저의 F11 전체화면은 영상 플레이어 전체화면과 구분합니다. F11 상태에서도 기본 모드 개선을 사용하며, 영화관 모드라면 표시 영역의 비율로 세로 배치 여부를 판단합니다.

## Chrome 설치

1. 확장 프로그램 폴더를 지우거나 옮기지 않을 위치에 둡니다. ZIP으로 받았다면 먼저 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭합니다.
5. `manifest.json`이 들어 있는 폴더 자체를 선택합니다.
6. 설치 전에 열어 둔 YouTube 탭은 **처음 한 번 새로고침**합니다. 이후 배치 전환에는 새로고침이 필요하지 않습니다.
7. 주소창 옆 확장 프로그램 메뉴에서 **유튜브 라이브 ui**를 고정하면 스위치를 쉽게 열 수 있습니다.

## Microsoft Edge 설치

1. Edge 주소창에 `edge://extensions`를 입력합니다.
2. **개발자 모드**를 켭니다.
3. **압축 풀린 파일 로드**를 클릭합니다.
4. `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 설치 전에 열어 둔 YouTube 탭을 처음 한 번 새로고침합니다.

스토어에 게시한 확장 프로그램이 아닌, 로컬 폴더를 읽는 개발자 모드 설치입니다. 설치 폴더를 이동하면 기존 확장을 제거하고 새 위치에서 다시 불러와야 합니다. Chrome과 Edge의 설정은 각각 저장됩니다.

## 사용

1. 진행 중이고 채팅이 열린 YouTube 라이브 방송을 엽니다.
2. 확장 아이콘을 열어 **라이브 화면 개선**을 켭니다.
3. 기본 모드에서는 원래 영상·채팅 위치를 유지하면서 채팅 높이와 추천 영상 배치를 개선합니다.
4. 영상 → 채널·제목·설명 → 채팅 순서로 보려면 플레이어의 **영화관 모드** 버튼을 누르고 창을 세로로 길게 조절합니다.
5. 영화관 모드에서 가로로 넓히면 영상·채팅은 원래 배치로 돌아가고, 추천 카탈로그는 채널·설명 아래에 표시됩니다. 확장 기능을 끄면 모든 모드에서 YouTube 원래 배치를 사용합니다.

채팅 메시지는 채팅 영역에서, 길어진 방송 설명은 방송 정보 영역 안에서 스크롤합니다. 추천 영상과 댓글은 페이지를 아래로 스크롤해 접근합니다. 원래 YouTube가 제공하지 않거나 아직 불러오지 않은 댓글은 확장이 새로 만들지 않습니다.

## 데이터와 권한

- 권한은 설정 저장용 `storage`입니다.
- 콘텐츠 스크립트는 `https://www.youtube.com/`의 최상위 페이지에서만 실행됩니다. 채팅 iframe 내부에 별도 스크립트를 주입하지 않습니다.
- 외부 서버, 분석 도구, 계정 로그인, API 키를 사용하지 않습니다.
- 영상 또는 채팅을 복제하거나 새 iframe을 생성해 대체하지 않습니다.
- 다른 영상으로 이동할 때 YouTube가 하는 정상적인 로딩은 배치 전환의 재로딩 여부와 구분해야 합니다.

## 현재 검증 상태

**2026-10-19, 1.0.11의 기본 모드 추천 제한·채팅 스크롤 추적·12px 하단 여백과 세로 영화관 모드의 여백 제거를 실제 Edge·YouTube 라이브에서 확인했습니다.** 실제 사이트 확인과 로컬 모의 시험의 범위는 아래와 같습니다.

### 1.0.11 실제 Edge·YouTube 라이브 확인

### 아직 확인하지 못한 항목

- **Chrome**에서의 실제 설치·라이브 동작은 검증하지 않았습니다.
- 실제 YouTube 플레이어 **전체화면 진입**은 자동화로 확인하지 못했습니다. 관련 조건 처리는 모의 단위 시험에서만 확인했습니다.
- 실제 브라우저에서 **확장 아이콘 팝업의 ON/OFF 스위치를 직접 조작하는 동작**은 확인하지 않았습니다. 설정 변경 처리는 모의 환경에서만 확인했습니다.
- 실제 라이브 스트림의 **장시간 무중단 재생**과 **채팅 프레임 재로드 횟수 계측**은 수행하지 않았습니다. 재생 진행·채팅 갱신 관찰과 로컬 재로드 0회 결과를 장기 무중단 보장으로 해석하지 않습니다.

YouTube는 화면 구조를 바꿀 수 있으므로 구조 변경에 따라 업데이트가 필요할 수 있습니다. 다른 YouTube 레이아웃 변경 확장과 동시에 사용하면 충돌할 수 있습니다.

## 업데이트와 제거

- 파일을 업데이트한 뒤 확장 관리 화면에서 이 확장의 **새로고침**을 누르고 열려 있는 YouTube 탭도 새로고침합니다.
- 잠시 원래 화면을 사용하려면 확장 아이콘에서 기능을 끕니다.
- 완전히 제거하려면 확장 관리 화면의 **삭제**를 사용합니다. 필요하면 열린 YouTube 탭을 새로고침합니다.
