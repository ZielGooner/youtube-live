# 유튜브 라이브 ui

<img src="icons/icon128.png" width="80" height="80" alt="빨간색 배경 안에 흰색 L 아이콘">

Chrome·Microsoft Edge용 YouTube 라이브 화면 개선 확장 프로그램입니다. 현재 버전은 **1.1.0**이며, Manifest V3를 사용합니다.

1.1.0은 기존 배치를 유지하면서 스크롤 처리·배치 갱신·팝업 설정 조회를 최적화한 버전입니다. 기본 모드 스크롤은 기존 요소 참조를 재사용하고, 숨겨진 탭이나 기능 OFF 상태의 불필요한 작업을 줄였습니다. 중복 CSS도 정리했습니다. 실제 성능 향상 수치를 측정한 벤치마크는 아닙니다.

## 주요 기능

| 화면 | 일반 추천 영상 | 채팅 배치 |
|---|---|---|
| 가로 기본 모드 | 한 줄 최대 4개 | 기존 오른쪽 채팅이 페이지 스크롤을 따라옴 |
| 세로 기본 모드 | 한 줄 최대 2개 | 기존 오른쪽 채팅이 페이지 스크롤을 따라옴 |
| 가로 영화관 모드 | 한 줄 최대 4개 | YouTube 원래 영화관 배치 유지 |
| 세로 영화관 모드 | 한 줄 최대 3개 | 영상·채널·제목·설명 아래부터 화면 하단까지 채움 |

- 추천 영상은 채널·설명 아래에 표시하며, 좁은 화면에서는 열 수가 줄어듭니다. 세로 화면의 Shorts도 확대합니다.
- 기본 모드의 채팅 하단에는 12px 여백을 둡니다. 세로 영화관 모드에는 하단 여백을 두지 않습니다.
- 세로 영화관 모드에서는 YouTube 상단바를 숨기고, 채팅 입력 영역이 화면 안에 표시되도록 높이를 계산합니다. 제목은 채널 옆에 한 줄로 표시합니다.
- 페이지 표시 영역의 너비가 높이의 103% 이하이면 세로 배치를 사용합니다. 브라우저 창의 외곽 크기가 아닌 실제 웹페이지 영역으로 판단합니다.
- 기존 영상·채팅 요소를 활용하며, 배치 변경을 위해 영상이나 채팅 iframe을 새로 만들거나 재로딩하지 않습니다.
- 주요 채팅·실시간 채팅 필터는 자동 변경하지 않습니다. 자동 재생 설정도 변경하지 않습니다.
- 창 크기 변경과 YouTube 내부 영상 이동에 대응합니다. 확장 아이콘에서 기능을 켜거나 끌 수 있습니다.
- 채팅이 없는 일반 영상, 종료된 방송의 채팅 다시보기, 플레이어 전체화면·미니플레이어에서는 기본 화면을 유지합니다.

## 설치

1. 이 저장소를 내려받거나 복제합니다. ZIP으로 받았다면 압축을 풉니다.
2. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`를 엽니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램 로드** 또는 **압축 풀린 파일 로드**를 누릅니다.
4. 이 저장소의 루트 폴더, 즉 `manifest.json`이 있는 폴더를 선택합니다.
5. 설치 전에 열어 둔 YouTube 탭을 한 번 새로고침합니다.

별도의 빌드나 패키지 설치는 필요하지 않습니다. 스토어 배포가 아닌 개발자 모드 설치이며, 설치 후 폴더를 옮기지 마세요. 업데이트한 뒤에는 확장 관리 화면에서 확장을 새로고침하고 YouTube 탭도 새로고침합니다.

## 권한과 데이터

설정 저장용 `storage` 권한만 요청하며, 콘텐츠 스크립트는 `https://www.youtube.com/*`에서 실행됩니다. 외부 서버·분석 도구·API 키를 사용하지 않습니다. 채팅 iframe 내부에는 별도 스크립트를 주입하지 않습니다.

## 검증 범위

2026-10-19에 최적화 버전 **1.1.0**을 실제 **Edge·YouTube 라이브**에서 검증했습니다. 가로 기본·영화관 모드 4열, 세로 기본 모드 2열, 세로 영화관 모드 3열, 기본 모드 채팅의 스크롤 추적·12px 하단 여백, 세로 영화관 모드의 하단 여백 없음·입력 영역 전체 표시, 영화관→기본 모드의 재생 바 크기 복구를 확인했습니다. 전환 중 재생이 진행됐고 가로 넘침은 없었습니다. 모의 환경에서는 배치 로직 **80개**와 팝업 **15개**, 합계 **95개 시험 통과** 및 JavaScript 문법 검사 통과를 확인했습니다.

Chrome에서의 실제 설치·라이브 동작, 실제 플레이어 전체화면 진입, 확장 팝업 스위치의 직접 조작, 장시간 연결 안정성과 실제 채팅 프레임 재로드 횟수는 확인하지 않았습니다. 새로고침 후 재생 버튼을 눌러야 한다는 증상은 재현하지 못했으며, 자동 재생 문제를 해결한 버전으로 간주하지 않습니다. YouTube의 화면 구조 변경이나 다른 레이아웃 확장과의 충돌에 따라 수정이 필요할 수 있습니다.

자세한 사용 방법·제약·버전별 검증 기록은 [README.ko.md](README.ko.md)를 참고하세요.

## 개발 확인

Node.js가 설치된 환경에서 실행합니다. 추가 의존성 설치는 필요하지 않습니다.

```sh
npm test
npm run check
```

로직 시험은 모의 DOM을 사용하며 실제 브라우저 검증을 대체하지 않습니다.
